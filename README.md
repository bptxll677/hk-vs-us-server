## 免备案跳过的具体是什么

ICP备案是对中国大陆境内机房的要求。只要服务器在大陆（或者用大陆CDN），域名对外提供网站服务就得备案。审核周期通常10–20个工作日，取决于省份、主体类型和材料完整度；个人主体能备案的网站类型也有限制，内容审核更严。

用港澳或境外节点之后，这个环节就被跳过了：域名解析过去，网站当天就能访问。省掉的是这几件事——

- 等审核的时间成本
- 主体材料、核验拍照那一套流程
- 备案期间网站无法对外服务的空窗期
- 因内容或资质不符被驳回、重新提交的返工

外贸站、独立开发者、临时项目偏好香港节点，主要原因就在这里。

## 「免备案」不等于没人管

这里有个常见误解值得单独说一句。

免备案免掉的只是大陆的ICP许可申请环节，不等于网站可以随便放内容。按《网络安全法》的要求，真实身份认证、违法信息处置这些义务依然存在，服务商也会做实名和使用规范管理。换句话说，免的是流程，不是责任。

还有一点：搜索引擎收录不受服务器地域限制。用香港服务器一样可以正常做优化，关键还是内容质量和HTTPS响应速度。

## 配置怎么选：1核2G到底够不够

这是被问得最多的一个问题，答案取决于你跑什么。

1核2G属于轻负载、单线程定位。系统加运行环境本身会占掉600–800MB内存，留给网站程序的可用内存在1.2–1.4GB之间。在这个前提下：

**能跑稳的场景**——个人博客、小型内容站（轻量主题、插件控制在10个以内）、企业展示站、B2B询盘型外贸站。有第三方实测数据给出的参考是：并发50以下时页面加载1–2秒，CPU占用低于30%，内存占用约600MB，日均500–2000UV的量级可以撑住。

**跑不动的场景**——WooCommerce这类电商站、15–20个插件以上的重型WordPress、日均UV超过2000的内容站、视频或大文件下载站、多站点同机部署。这些情况直接上2核4G起步更省心。

还有两件比配置数字更影响体验的事：

1. **硬盘必须是SSD**。机械盘的数据库随机读写会把站点拖慢，选盘时看清SSD字样。
2. **缓存和CDN不能省**。低配机器上，页面缓存（Nginx FastCGI Cache或缓存插件）+对象缓存（Redis）能挡掉大部分请求；静态资源走CDN后，源站带宽压力会明显下降。
